# ScienceArena

This repository is the reproducibility release for **ScienceArena: Benchmarking
LLMs on Latest Scientific Olympiad Competitions**. It contains the solver,
rubric-judge, modality-routing, dataset-validation, repeated-call, cross-family
judge, aggregation, and paper-analysis code used by the camera-ready study.

The interactive demo is available at <https://science-arena-review.onrender.com/>.

## What is reproducible

There are two complementary reproduction modes:

1. **Offline paper replay.** Rebuild the paper-facing tables and verify their
   source hashes from frozen result artifacts. This requires no API key and is
   the recommended first check.
2. **Live end-to-end rerun.** Validate inputs, probe exact API routes, solve
   interleaved problem turns, judge each answer against the official rubric,
   and aggregate scores. Live generations can change as hosted models and
   provider infrastructure evolve; the prompts, routing rules, scoring code,
   input hashes, and archived responses remain auditable.

All released raw model artifacts omit hidden chain-of-thought. They retain only
visible responses, scores, compact request evidence, and provenance needed for
auditing.

## Quick start

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip setuptools
pip install -e '.[api,analysis,dev]'

# Rebuild paper-facing CSV/Markdown files without API calls.
python scripts/reproduce_tables.py --output reproduced

# Run tests and the repository-wide credential guard.
pytest
python scripts/verify_release.py
```

Large inputs and raw no-CoT run ledgers are GitHub Release assets rather than
Git blobs. List and download them with:

```bash
python scripts/download_artifacts.py --list
python scripts/download_artifacts.py --name inputs-2026 --extract
```

While the repository is private, set `GITHUB_TOKEN` to a token with read access.
No GitHub token is needed after the repository and release become public.

## Run the 2026 pipeline

The API key is read only from an environment variable. Never put it in a file,
command-line flag, notebook, or commit.

```bash
export QIHOO_API_KEY='YOUR_KEY'

# First download/extract inputs-2026, then validate one competition.
python scripts/run_2026.py validate --contest ipho2026

# Probe every exact route before a paid run.
python scripts/run_2026.py probe --contest ipho2026

# Solve, judge, and aggregate. Each stage is resumable.
python scripts/run_2026.py solve --contest ipho2026 --workers 8
python scripts/run_2026.py judge --contest ipho2026 --workers 8
python scripts/run_2026.py aggregate --contest ipho2026
```

The production endpoint is `https://api.360.cn/v1/chat/completions` (with the
Responses endpoint used only by routes whose frozen manifest requires it).

## Non-negotiable modality rules

- A verified multimodal solver receives the **original frozen official
  question-page PNG bytes directly** as API image blocks. It never receives a
  caption generated by another model in place of those pixels.
- A genuine text-only solver receives the reviewed, answer-blind,
  question-only staticization and exactly zero image blocks.
- Staticization can inspect only question text and question images. Official
  answers, solutions, rubrics, and solution images are excluded from its input.
- The production rubric judge is vision-capable because chemistry and physics
  gold material may itself be graphical. It receives the candidate response,
  official answer/solution/rubric, frozen criterion maxima, and original
  question/solution PNGs when supplied by the item.

These contracts are enforced by validation, capability proofs, payload hashes,
and tests; see [docs/PIPELINE.md](docs/PIPELINE.md).

## Reproducibility boundary

The four 2026 columns, solver repeats, and six-judge study retain compact
response/score artifacts and full protocol evidence. Several older paper cells
predate the sealed runner; their final aggregates and runnable protocol are
released, but some original provider wire trees no longer exist. The evidence
map labels those cells `aggregate replay` rather than claiming byte-identical
raw regeneration. The controlled modality experiment likewise retains its
audited aggregate report but not its original raw response tree.

## Security

No API key is present in this repository or its release assets. CI rejects
credential-shaped strings, private-key material, committed `.env` files, hidden
provider reasoning fields, and oversized Git blobs. See
[SECURITY.md](SECURITY.md).
