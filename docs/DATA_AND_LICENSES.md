# Data provenance and rights

Repository-authored code is MIT-licensed. This does not relicense official
olympiad problems, solutions, marking schemes, logos, third-party papers,
provider responses, or other externally authored content.

Official materials are included or linked solely to support scholarly
verification of the benchmark. Their original organizers and publishers retain
their rights. Users are responsible for checking source-site terms before
redistribution or commercial use.

The release separates:

- small metadata and hashes committed to Git;
- official page renders and canonical datasets in input assets;
- model outputs and judge records in no-CoT run assets;
- the final paper source and PDF.

The dataset contains public competition material and model-generated responses,
not participant submissions. Human ranking files, where used only to derive
medal reference aggregates, should be redistributed only when their official
source permits it. The benchmark code does not require contestant names or
other personal identifiers.
